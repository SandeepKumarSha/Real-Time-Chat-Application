# 💬 Hello – Real-Time Chat Application

A modern **Real-Time Chat Application** built with **Python** that enables users to communicate instantly over a network. The application features secure user authentication, real-time messaging, online user management, and a clean, user-friendly interface designed to provide a seamless chatting experience.

---

## ✨ Features

* 🔐 User Registration & Login
* 💬 Real-Time Messaging
* 👥 Group Chat Support
* 📩 Private One-to-One Chat
* 🟢 Online Users List
* ⌨️ Press Enter to Send Messages
* 🕒 Message Timestamps
* 🎨 Modern and User-Friendly Interface
* ⚡ Fast Message Delivery
* 💾 SQLite Database for User Management

## 🚀 Installation

### 1. Clone the Repository

```bash
git clone https://github.com/SandeepKumarSha/Real-Time-Chat-Application.git
```

### 2. Navigate to the Project Directory

```bash
cd Real-Time-Chat-Application
```

### 3. Create a Virtual Environment (Optional)

**Windows**

```bash
python -m venv venv
venv\Scripts\activate
```

**macOS/Linux**

```bash
python3 -m venv venv
source venv/bin/activate
```

### 4. Install Dependencies

```bash
pip install -r requirements.txt
```

### 5. Start the Server

```bash
python server.py
```

### 6. Launch the Client

```bash
python client.py
```

## 📖 How It Works

1. Create a new account or log in with existing credentials.
2. Connect to the chat server.
3. View available online users.
4. Send and receive messages instantly.
5. Participate in group chats or private conversations.
6. Enjoy a smooth, real-time communication experience.
